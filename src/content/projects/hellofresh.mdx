## Overview

Work on HelloFresh’s mobile platform spans native iOS and React Native, with emphasis on sustainable architecture, cross-platform integration, and production reliability.

## Role

Senior Mobile Engineer — contributing to system-level improvements and feature delivery without exposing internal implementation details.

## Context

A large, multi-team mobile codebase serving millions of customers. Changes must balance speed, quality, and long-term maintainability.

## Areas of focus

### Authentication

Improving reliability and clarity around sign-in, session lifecycle, and error handling so auth failures are diagnosable and user-visible states stay consistent.

### Mobile observability

Strengthening signals from mobile clients — logging, tracing hooks, and patterns that help engineers understand failures in production.

### Modularization

Moving toward clearer module boundaries so teams can ship with less coupling and safer refactors.

### Localization

Supporting scalable localization workflows and infrastructure so product strings and regional behavior remain manageable as the app grows.

### React Native / native integration

Bridging native and React Native surfaces — shared contracts, navigation boundaries, and pragmatic integration patterns.

## Engineering challenges

- Coordinating native and cross-platform codepaths without duplicating business logic unnecessarily.
- Evolving architecture while the product continues to ship.
- Keeping observability useful without overwhelming engineers or users.

## My contribution

Hands-on engineering across the areas above: design discussions, implementation, reviews, and incremental migration work — always at a level appropriate for a public portfolio.

## Technologies

iOS, Swift, React Native, TypeScript, JavaScript, mobile architecture, observability tooling (as applicable internally).

## Lessons learned

Large consumer apps reward small, reversible steps: modular boundaries, measurable reliability work, and tooling that pays back daily.
